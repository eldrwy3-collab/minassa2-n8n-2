# netregent — Automation Intelligence

This version removes the n8n dependency. It reads the separate workflow knowledge repository in the browser and performs local deterministic matching and workflow-map rendering.

Data source:
https://raw.githubusercontent.com/eldrwy3-collab/maktaba-data/refs/heads/main/ultimate_6_platforms_database_ultimate.json

Features: six execution platforms, searchable catalog, domain/subdomain navigation, local solution composer, dynamic map, explanations, alternatives, local demo accounts, feedback form, SEO metadata and defensive client-side protections.

Important: local accounts/feedback are demo browser storage. Production authentication, database storage, email delivery and any server-side AI must be implemented behind a secure backend.
